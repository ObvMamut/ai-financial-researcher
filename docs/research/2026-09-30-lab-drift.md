## What these tests do and do not measure

These limits were disclosed before the run (Method in `docs/workflow/backtest.md`), and the result
is read with them:

- **Release date, not filing date.** The lab anchors drift at the 8-K Item 2.02 release date. A
  live run anchors it at the 10-Q/10-K filing date, which is the same day for many large filers
  and weeks later for others. The lab measures the effect itself; it does not replicate the live
  leg's timing.
- **Every Item 2.02 8-K counts.** An off-cycle release, such as a preannouncement or a restated
  quarter, becomes the drift event and restarts `earn_window`'s 91-day cadence.
- **Two benchmarks in one cross-section.** The pooled US cross-section mixes ^GSPC for every sp500
  row, cross-listed names included, with ^NDX for the nq100-only names. The beta-adjusted target
  softens this but does not remove it.
- **XOM contributes almost nothing.** SEC's ticker directory maps XOM to a successor CIK whose
  filing history begins 2026-07-01, so XOM supplies almost no events. It was resolved, so it does
  not appear as unavailable. This is missing data and was not special-cased. It is one name of 119.
- **D3 is an approximation.** The next release is extrapolated as the last release plus 91 days,
  ±7 days. It is not a calendar.
- **Survivorship.** Today's constituents flatter the early years. That favours finding an effect,
  and none was found.

None of these limits could turn a t of −0.67 (D1) or −0.03 (D2) into one above +2.5.
